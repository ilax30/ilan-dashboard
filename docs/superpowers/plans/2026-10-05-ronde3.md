# Ronde 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Eigen agendapagina (Fantastical-stijl, 13 weken), Notities (Apple Notes-simpel) en Financiën (vaste lasten + betalingen), elk met dashboardtegel.

**Architecture:** Nieuwe routes `#/agenda`, `#/notities`, `#/financien` in de bestaande shell. Pure logica in `src/lib/*` (getest); opslag via een store-interface met Supabase- en localStorage-variant (zoals taken), realtime voor sync. Tegels hergebruiken `WidgetCard`.

**Tech Stack:** React 19, TypeScript, Supabase (Postgres + RLS + realtime, Edge Function), Vitest (TZ Amsterdam), Phosphor.

**Spec:** `docs/superpowers/specs/2026-10-05-ronde3-agenda-notities-financien-design.md`

- Na elk deel (A, B, C): tests + tsc + build, merge naar main en push (Ilan: "na elk deel live").
